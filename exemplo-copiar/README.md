# Exemplo para novos desafios

Esta pasta serve como modelo para adicionar novos exercícios do HackerRank ao repositório.

## Como usar

1. Copie a estrutura da pasta `exemplo-copiar/`.
2. Crie uma nova pasta com o nome do desafio.
3. Adicione o arquivo `index.js` com a solução em JavaScript.
4. Crie um `README.md` com:
   - título do desafio;
   - descrição do problema;
   - exemplo de entrada e saída;
   - instruções de execução;
   - complexidade da solução.

## Estrutura sugerida

```text
nome-do-desafio/
├── README.md
└── index.js
```

## Observação

Os arquivos desta pasta ficam vazios para que você possa reutilizar a base e manter o padrão do repositório.
