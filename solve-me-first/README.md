# Solve Me First

Solução em JavaScript para o desafio **Solve Me First** do HackerRank. Dado dois números inteiros, a função `solveMeFirst(a, b)` retorna a soma deles.

## Como funciona

A função recebe os valores `a` e `b` como parâmetros e retorna `a + b`.

```js
solveMeFirst(2, 3); // 5
```

O arquivo [`index.js`](./index.js) contém a implementação e uma chamada de exemplo com os valores `1` e `2`, cujo resultado é impresso no console.

## Como executar

É necessário ter o [Node.js](https://nodejs.org/) instalado. Na pasta `solve-me-first`, execute:

```bash
node index.js
```

Saída esperada:

```text
3
```

## Complexidade

- **Tempo:** `O(1)`.
- **Espaço adicional:** `O(1)`.
